# Blog da Turma (Java)

Aplicação de console em Java 17 com MariaDB (Docker). Camadas: models, data, services, views, controllers.

    docker compose up -d
    mvn -q compile exec:java      # execute na pasta onde está o .env

Menu: 1 listar · 2 cadastrar · 3 entrar · 4 criar · 5 abrir · 6 editar · 7 excluir · 8 comentar · 9 sair da conta · 0 encerrar.
Documentação completa (UML, casos de uso, ER, fluxogramas): ../Blog_da_Turma_Documentacao.pdf
